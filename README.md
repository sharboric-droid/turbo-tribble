# Quiz: GitHub Collaboration Simulation

**Q1. What is the purpose of creating a feature branch in GitHub?**

- To delete old code
- To isolate development work from the main branch
- To merge unrelated repositories
- To change repository settings

✅ **Correct Answer**: To isolate development work from the main branch

---

**Q2. Which GitHub feature allows team members to review and approve code before merging?**

- Issues
- Pull Requests
- Commits
- Branches

✅ **Correct Answer**: Pull Requests

---

**Q3. What is the correct action when a bug is found during QA review?**

- Delete the repository
- Create a new branch
- Create an issue and link it to the pull request
- Merge the pull request immediately

✅ **Correct Answer**: Create an issue and link it to the pull request

---

**Q4. How can tasks be visually tracked in GitHub for agile development?**

- Using GitHub Projects board
- Using commit history
- Using repository settings
- Using README files

✅ **Correct Answer**: Using GitHub Projects board

---

**Q5. What happens when a pull request is merged into the main branch?**

- The repository is deleted
- The feature branch is automatically removed
- The changes become part of the main codebase
- The issue is closed automatically

✅ **Correct Answer**: The changes become part of the main codebase
